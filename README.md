# Game Winrate

친구들과 진행한 게임의 승률과 내기 정산을 기록하는 Next.js 앱입니다. 정산 장부에 판을 추가하고 최종 저장하면 Supabase 기록으로 승률·전적·누적 금액을 자동 계산합니다. 경기 결과를 따로 입력하거나 노션을 업데이트할 필요가 없습니다.

## 사용 방법

1. 날짜와 게임, 1인당 판돈을 선택합니다.
2. 참가 멤버와 진 사람을 선택하고 `이번 판 추가`를 누릅니다.
3. 팀전이면 `팀전`을 체크합니다. 이긴 사람끼리, 진 사람끼리 각각 한 팀인 경기만 체크하세요.
4. `최종 저장 · 승률 반영`을 누르면 정산과 통계가 함께 반영됩니다. 저장한 모임을 삭제하면 해당 통계도 제외됩니다.

진행 중인 기록은 브라우저에 임시 저장합니다. 최종 저장 전에는 승률에 반영하지 않습니다. 기원이 참가한 판만 기원 승률·전적·추이에 반영하고, 참가자별 승률에는 모든 참가자를 반영합니다. 개인전의 공동 승자를 같은 팀으로 추정하지 않습니다. 파트너 추천과 팀 상성표는 팀전만 사용합니다.

## 데이터

- `settlement_sessions`: 정산 모임. `rounds`의 각 판에 `id`, `amounts`, `game`, `date`, `teamGame`을 저장합니다. 판별 금액 부호로 승패를 계산하며, 모임 합계로 승패를 판정하지 않습니다.
- `game_history`: 기존 노션 경기 16건을 원래 ID로 보존한 기록. 새로운 경기 입력에는 사용하지 않습니다. 생성 SQL은 `supabase/game_history.sql`입니다.
- 게임 종류와 팀 구성을 저장하지 않았던 예전 정산은 `미분류` 개인전으로 집계합니다. 날짜는 날짜 형식의 모임 제목, 그 외에는 저장 시각의 한국 날짜를 사용합니다.
- 노션 API와 SDK는 사용하지 않습니다. 노션 원본은 수정하거나 삭제하지 않았습니다.

## 로컬 실행

```bash
npm install
cp .env.local.example .env.local
npm run dev -- --port 3001
```

[http://localhost:3001](http://localhost:3001)에서 확인할 수 있습니다.

`.env.local`에 `SUPABASE_URL`, `SUPABASE_SECRET_KEY`를 설정합니다. Secret key는 서버에서만 사용하며 브라우저나 Git 저장소에 공개하지 않습니다. 기존 로컬 환경 파일의 노션 변수는 더 이상 사용하지 않습니다.
